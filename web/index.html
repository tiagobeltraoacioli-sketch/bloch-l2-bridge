01 / THE ARCHITECTURE

Separate networks.
Explicit responsibilities.

The planned bUSDC asset would be backed by USDC held in the reviewed Ethereum vault. It is a bridged representation, not USDC issued directly on Bloch by Circle.

01

Lock source USDC

The Ethereum vault design covers deposits, threshold-authorized releases and replay protection. Local tests and build hashes do not establish a live deployment, real custody independence or backing.

REFERENCE COMPONENTS
02

Account on native L1

The native gateway implementation tracks imports, burns and backing separately for each source route. Native network activation and complete source-to-native integration remain pending.

INTEGRATION IN DEVELOPMENT
03

Verify before release

Contract identity, source finality, committee configuration and native authorization must be established before minting or releasing funds. Source committee attestations are not independent finality proofs.
